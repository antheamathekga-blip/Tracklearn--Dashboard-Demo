# TrackLearn Dashboard Demo

Responsive purple dashboard UI for the TrackLearn LMS Activity Monitoring System.

## Features
- Purple gradient themed responsive dashboard
- Student activity stats cards
- Inactive student alerts > 3 days
- Mobile and Desktop support with Tailwind CSS

## Tech Used
- HTML5
- Tailwind CSS CDN

## Note
This is the Phase 2 Frontend UI. 
Backend logic is in TrackLearn-Java repo.
